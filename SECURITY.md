# Security policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| v1.x     | :white_check_mark: |

## Reporting a vulnerability

We first appreciate and are very thankful that you've found a vulnerability issue in NebulaPanel! By disclosing such issue to NebulaPanel development team you are helping NebulaPanel to become a much more safer project than before! ;)

To protect the existing users of NebulaPanel, we kindly ask you to not disclose the vulnerability to anyone except the NebulaPanel development team before a fix has been rolled out. Send an email to `wanghe@fit2cloud.com` instead.
