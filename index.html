Linux 服务器运维面板

NebulaPanel 基于 Go + Vue 3 构建，提供主机监控、容器管理、网站部署、数据库运维与一键备份的一站式解决方案。开箱即用，一条命令完成部署。

立即安装 → 了解功能
root@server ~ 一键安装 
# 下载安装脚本并执行（全程交互式）
curl -fsSL https://resource.hongkongyun.top/install.sh -o install.sh
sudo bash install.sh

核心功能

从裸机到应用，一个面板全部搞定

🖥️

主机监控

实时查看 CPU、内存、磁盘、网络负载，支持历史曲线与告警通知，异常一眼可见。

🐳

容器管理

基于 Docker 的容器、镜像、网络、存储卷与 Compose 编排管理，可视化操作无需记命令。

🌐

快速建站

深度集成 WordPress、Halo 等主流建站程序，一键绑定域名、自动申请 SSL 证书。

🗄️

数据库运维

MySQL、PostgreSQL、Redis、MongoDB 统一管理，支持备份、恢复与慢查询分析。

🛡️

安全防护

防火墙规则、IP 白名单、Fail2ban、WAF 与操作日志审计，全方位保障服务器安全。

💾

一键备份

网站、数据库、配置一键打包备份，支持本地与云存储（S3、OSS、七牛等）异地容灾。

⏱️

计划任务

可视化配置 Cron 定时任务，支持脚本、备份、日志清理与自定义 Shell 命令。

📁

文件管理

在线文件浏览、编辑、上传下载与权限修改，内置代码编辑器，改配置不用连 SSH。

🤖

AI 能力集成

内置 AI 网关与模型管理，可接入本地大模型或云端 API，为运维场景提供智能辅助。

快速安装

支持 Debian / Ubuntu / CentOS / Rocky / AlmaLinux

1

准备环境

一台 x86_64 架构的 Linux 服务器，root 权限，能访问外网。Docker 会自动检测安装。

2

执行脚本

运行 sudo bash install.sh，按提示填写端口、安全入口、管理员账号密码。

3

访问面板

安装完成后浏览器打开 http://服务器IP:端口/安全入口 即可登录。

4

日常管理

使用 npctl 命令管理服务：start / stop / restart / status / user-info。

💡
安装过程全程交互，默认值可直接回车采用：安装目录 /opt、端口 9999、安全入口 nebula、账号 admin。 安装结束会询问是否将 Docker 镜像源替换为加速地址，按需选择即可。

安装说明

部署前请知悉以下事项

🔧

架构限制

当前发布包仅提供 amd64（x86_64）。ARM64 服务器安装脚本会直接提示不支持，需从源码自行编译。

📦

Docker 依赖

脚本会先检测 Docker：已安装则跳过，未安装则通过官方源自动安装。部署采用 host 网络模式。

🗂️

数据目录

默认安装到 /opt/NebulaPanel，配置、数据库、日志、备份均在此目录下，重装不会清空。

🔄

版本更新

V1.0.0 已移除面板内置在线更新功能。升级方式为获取新二进制后重新执行安装脚本，数据保留。

🔐

安全入口

安装时设置的安全入口会作为访问路径后缀，建议使用不易猜测的字符串，降低被扫描风险。

🛠️

故障排查

服务异常时先执行 npctl status 查看容器状态，再用 npctl logs 查看实时日志定位问题。
