NebulaPanel은 리눅스 서버 관리를 위한 오픈 소스 현대 웹 기반 제어판입니다.

- **효율적인 관리**: 사용자 친화적인 웹 그래픽 인터페이스를 통해 NebulaPanel은 사용자가 리눅스 서버를 손쉽게 관리할 수 있도록 합니다. 주요 기능으로는 호스트 모니터링, 파일 관리, 데이터베이스 관리 및 컨테이너 관리가 포함됩니다.
- **신속한 웹사이트 배포**: 인기 있는 오픈 소스 웹사이트 빌딩 소프트웨어인 WordPress와의 깊은 통합을 통해 NebulaPanel은 도메인 바인딩 및 SSL 인증서 구성을 단 한 번의 클릭으로 간소화합니다.
- **애플리케이션 스토어**: NebulaPanel은 다양한 고품질 오픈 소스 도구 및 애플리케이션을 선별하여 사용자가 쉽게 설치하고 업데이트할 수 있도록 합니다.
- **보안 및 신뢰성**: 컨테이너화 및 안전한 애플리케이션 배포 관행을 활용하여 NebulaPanel은 취약점 노출을 최소화합니다. 또한 통합 방화벽 관리 및 로그 감사 기능을 통해 보안을 강화합니다.
- **원클릭 백업 및 복원**: NebulaPanel의 원클릭 백업 및 복원 기능을 통해 데이터 보호가 간편해지며, 다양한 클라우드 스토리지 솔루션을 지원하여 데이터 무결성과 가용성을 보장합니다.

## 빠른 시작

아래 스크립트를 실행하고 프롬프트에 따라 NebulaPanel을 설치하세요:

```bash
git clone https://github.com/AxionMC/NebulaPanel.git && cd NebulaPanel && sudo bash scripts/install.sh
```

자세한 내용은 [문서](https://github.com/AxionMC/NebulaPanel)를 참조하세요.
