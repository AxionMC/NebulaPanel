------------------------------

NebulaPanel adalah panel kontrol berbasis web yang modern dan open-source untuk manajemen server Linux.

- **Manajemen Efisien**: Melalui antarmuka grafis web yang ramah pengguna, NebulaPanel memungkinkan pengguna mengelola server Linux mereka dengan mudah. Fitur utamanya mencakup pemantauan host, manajemen file, administrasi database, dan manajemen kontainer.
- **Penyebaran Situs Web Cepat**: Dengan integrasi mendalam perangkat lunak pembuatan situs web open-source populer WordPress, NebulaPanel menyederhanakan proses pengikatan domain dan konfigurasi sertifikat SSL, semuanya dapat dicapai hanya dengan satu klik.
- **Toko Aplikasi**: NebulaPanel menyediakan berbagai macam alat dan aplikasi open-source berkualitas tinggi, memudahkan instalasi dan pembaruan bagi penggunanya.
- **Keamanan dan Keandalan**: Dengan memanfaatkan teknologi kontainerisasi dan praktik penyebaran aplikasi aman, NebulaPanel meminimalkan paparan kerentanan. Keamanan lebih ditingkatkan melalui manajemen firewall terintegrasi dan kemampuan audit log.
- **Cadangan & Pulih Satu Klik**: Perlindungan data menjadi sederhana dengan fungsi cadangan dan pulih satu klik dari NebulaPanel, mendukung berbagai solusi penyimpanan cloud untuk memastikan integritas dan ketersediaan data.

## Panduan Cepat Memulai

Jalankan skrip di bawah ini dan ikuti petunjuk untuk menginstal NebulaPanel:

```bash
git clone https://github.com/AxionMC/NebulaPanel.git && cd NebulaPanel && sudo bash scripts/install.sh
```

Silakan merujuk ke [dokumentasi](https://github.com/AxionMC/NebulaPanel) kami untuk informasi lebih lanjut.
