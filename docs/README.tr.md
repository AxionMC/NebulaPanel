NebulaPanel, Linux sunucu yönetimi için modern, açık kaynaklı bir web tabanlı kontrol panelidir.

- **Verimli Yönetim**: Kullanıcı dostu bir web grafik arayüzü aracılığıyla, NebulaPanel kullanıcıların Linux sunucularını zahmetsizce yönetmelerini sağlar. Ana özellikler arasında ana bilgisayar izleme, dosya yönetimi, veritabanı yönetimi ve konteyner yönetimi yer alır.
- **Hızlı Web Sitesi Dağıtımı**: Popüler açık kaynaklı web sitesi oluşturma yazılımı WordPress ile derin entegrasyon sayesinde, NebulaPanel alan adı bağlama ve SSL sertifikası yapılandırma işlemlerini basitleştirir, hepsi sadece bir tıkla yapılabilir.
- **Uygulama Mağazası**: NebulaPanel, yüksek kaliteli açık kaynaklı araçlar ve uygulamalar sunar, kullanıcıların kolayca kurulum yapmalarını ve güncellemelerini sağlar.
- **Güvenlik ve Güvenilirlik**: Konteynerleştirme ve güvenli uygulama dağıtımı yöntemlerini kullanarak NebulaPanel, güvenlik açıklarını en aza indirir. Ayrıca, entegre güvenlik duvarı yönetimi ve günlük denetleme özellikleri ile güvenliği artırır.
- **Tek Tıkla Yedekleme ve Geri Yükleme**: NebulaPanel’in tek tıkla yedekleme ve geri yükleme işlevi, veri korumasını basitleştirir ve çeşitli bulut depolama çözümleriyle veri bütünlüğü ve erişilebilirliğini sağlar.

## Hızlı Başlangıç

**Tek Tuşlu Yükleme**

Aşağıdaki komutu çalıştırın ve NebulaPanel’i kurmak için yönergeleri takip edin:

```bash
git clone https://github.com/AxionMC/NebulaPanel.git && cd NebulaPanel && sudo bash scripts/install.sh
```

Daha fazla detay için [dokümantasyonumuza](https://github.com/AxionMC/NebulaPanel) göz atın.
